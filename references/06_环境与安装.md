# 环境与安装

## 安装 skill

```bash
git clone https://github.com/mjlens-spec/Doc-image-deck.git
zsh Doc-image-deck/scripts/install.sh
```

`install.sh` 把 skill 本体（`SKILL.md`、`LICENSE`、`agents/`、`references/`、`scripts/`）复制到 `~/.agents/skills/doc-image-deck/`，并在 `~/.claude/skills/` 与 `~/.codex/skills/` 各建一个指向它的链接，两个宿主共用一份文件；然后执行 `setup.sh` 安装运行环境。修改仓库里的文件后重跑 `install.sh --no-setup` 同步。只装给其中一个宿主时，照样运行 `install.sh`，另一个宿主的链接不影响使用。

## 运行环境（setup.sh）

运行环境放在 `$DOC_IMAGE_DECK_HOME`，默认 `~/.local/share/doc-image-deck/`，与 skill 文件分开，两个宿主共用。

| 项目 | 位置 / 来源 | 用途 |
|---|---|---|
| Python 3.10+ 虚拟环境 | `venv/`：numpy、scipy、opencv-python-headless、pillow、python-pptx、lxml、torch、fonttools；simple-lama-inpainting 用 `--no-deps` 安装（它锁定的旧版 Pillow 在 Python 3.13 上编译失败） | 全部脚本 |
| LaMa 权重 | `~/.cache/torch/hub/checkpoints/big-lama.pt`，196 MB，GitHub release，`curl -C -` 断点续传 | 去字修补 |
| poppler | Homebrew `poppler` | PDF 渲染与抽图 |
| 字体 | `~/Library/Fonts/`：`NotoSerifSC-wght.ttf`（google/fonts）、`NotoSansCJKsc-{Light,DemiLight,Regular,Medium,Bold,Black}.otf`（notofonts/noto-cjk），均为 SIL OFL | 可编辑版的字体 |
| 微软雅黑 | 不自动下载 | 白板稿字体；缺失时仅本机显示被替换 |
| OCR 工具 | `bin/ocrbox`，由 `scripts/editable/ocrbox.swift` 用 `swiftc` 编译（需 Xcode 命令行工具） | Apple Vision 文字识别 |
| Codex CLI | 需以 ChatGPT 账号登录（`codex login`） | 生图 |
| Microsoft PowerPoint for Mac | `/Applications` | 导出 PDF、比对、标定 |
| 标定 | `calibration.json`：字重实测与行距→基线查找表，打开 PowerPoint 约 1 分钟 | 可编辑版文本框定位 |

`setup.sh --check` 只检查不修改；`--no-fonts` 不下载字体；`--no-calib` 跳过标定。PowerPoint 或字体版本变化后删除 `calibration.json` 重跑 `setup.sh`。

## 资源占用

- 可编辑还原阶段每个进程峰值约 1.5 GB（LaMa 在 Apple GPU 上，已限制显存水位）；16 GB 内存最多 2 进程。
- 生图 4 路并发，受 ChatGPT 套餐的生图额度限制；74 页的稿件约 40 分钟。
