# 阶段 3 · 合成图文版

## project.json 里的相关字段

| 字段 | 默认 | 说明 |
|---|---|---|
| `logos` | `[]` | 每项 `{"light": 浅底用 PNG, "dark": 深底用 PNG, "corner": "bl"｜"br"｜"tl"｜"tr", "height_in": 0.26, "name": "品牌 Logo"}`；只有一个版本时只写 `light` |
| `page_number` | 右下角 | `{"corner": "br", "skip_first": true, "skip_last": true, "format": "{:02d}", "font": "Arial", "size_pt": 11}`；`corner` 设为空字符串则不加页码 |
| `margin_in` | 0.8 | Logo 和页码离左右边缘的距离（英寸） |
| `footer_y_in` / `header_y_in` | 7.05 / 0.2 | 底部 / 顶部角落对象的上沿位置（英寸，页面高 7.5） |
| `upscale` | 2 | 生图放大倍数（LANCZOS） |

多个品牌并列时，先把联合 Logo 做成一张透明 PNG 再配置，一个角落只放一个 Logo 对象。Logo 文件用透明底 PNG，浅底用深色字标，深底用反白字标。

## 处理规则

1. 每页选用 `02_生图/raw/selected.json` 指定的版本，放大后存为 `03_合成/pNN.png`；嵌入 PPTX 时取 JPEG（质量 93、4:4:4）和 PNG 中较小的一个。
2. Logo 版本按角落区域平均亮度选择：亮度 < 110 用深底用版本。
3. 页码颜色按角落亮度选白色或灰色；角落灰度标准差 > 22（落在照片上）时加 50% 透明深色圆角底块。
4. 页面图片的替代文字写入本页全部文案，讲稿写入备注。
5. 导出 PDF 用 PowerPoint，与交付给客户的渲染一致。

## 检查

抽查封面、深色页、照片满版页、表格页各一页：Logo 和页码没有压到内容，深浅版本选对，页码清晰。压到内容时优先回阶段 2 重生成该页，其次调整角落或尺寸后重跑 `deck compose`。
